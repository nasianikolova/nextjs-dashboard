A full-stack invoicing dashboard built with the Next.js App Router. It covers authentication, server-side data fetching from a Postgres database, streaming with React Suspense, and a responsive dashboard layout.

Built as the capstone project for the MIT xPRO Professional Certificate in
Coding: Full Stack Development with MERN.
